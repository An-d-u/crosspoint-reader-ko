# TXT·MD 독서 화면

## 표시 방식

TXT와 MD는 내부 XHTML로 변환한 뒤 기존 EPUB의 `ChapterHtmlSlimParser`와 `Page`를 사용한다. 원본 파일은 수정하지 않는다. EPUB 자체의 처리 경로와 피드 화면은 변경하지 않는다.

- 글꼴·크기·줄 간격·화면 여백·문단 정렬·문단 들여쓰기·문단 추가 간격·자동 하이픈 처리는 EPUB과 같은 독서 설정을 사용한다.
- EPUB과 마찬가지로 문단 추가 간격을 켜면 장식적인 첫 줄 들여쓰기는 억제한다. 목록의 내어쓰기는 유지한다.
- TXT의 물리적인 줄바꿈을 문단 경계로 사용하고 빈 줄도 보존한다. TXT의 마크다운 기호는 해석하지 않는다.
- 화면 새로 고침 주기, 독서 화면 안티앨리어싱, 버튼 조작, 북마크, 진행률 지연 저장은 기존 TXT 독서 화면을 유지한다.
- XTC·XTCH에는 영향을 주지 않는다.

## MD 지원 범위

제목(`#`~`######`), 굵게·기울임·중첩 강조, 글머리표·번호 목록과 들여쓰기, 인용문, 구분선, 인라인 코드, 백틱/물결표 코드 블록, 링크 문구를 표시한다. 닫히지 않은 강조 기호는 일반 문자로 남긴다. 닫히지 않은 코드 블록은 파일 끝까지 코드로 취급한다.

피드와 같은 경량 지원이며 브라우저와 동일한 마크다운 엔진은 아니다.

- 제목은 독서 글꼴의 굵은 글씨와 문단 여백으로 구분한다.
- 코드는 독서 글꼴을 사용한다. 인라인 코드는 밑줄, 코드 블록은 들여쓰기로 구분하며 공백·줄바꿈을 보존한다. 구문 강조·전용 고정폭 글꼴·피드의 코드 테두리는 제공하지 않는다.
- 링크는 문구에 밑줄을 긋는다. 누르거나 외부 주소에 접속하지 않는다.
- 이미지는 `[설명]`으로 표시하고 로컬·외부 이미지 파일을 읽지 않는다.
- 표는 셀 구분자를 남긴 텍스트로 표시한다. 표 너비 계산·셀 테두리는 지원하지 않는다.
- 원시 HTML은 실행하거나 문서 구조로 해석하지 않고 문자 그대로 표시한다.
- 물리적인 한 행이 4,096바이트를 넘으면 그 행은 서식 해석 없이 끝까지 표시한다. 다음 행부터 서식 해석을 재개한다. 긴 행의 내용은 자르지 않는다.
- UTF-8 문서를 대상으로 하며 BOM, LF, CRLF, CR을 처리한다. 다른 문자 인코딩의 자동 변환은 제공하지 않는다.

## 캐시와 메모리

독서 캐시 디렉터리에 다음 파일을 생성한다.

- `text-source.tmp`: 순차 변환한 XHTML. 페이지 구성이 끝나거나 실패하면 제거한다.
- `text-pages.bin`: EPUB과 같은 직렬화 페이지 데이터.
- `index.bin`: 버전 5, 원본 크기·표시 설정·페이지 데이터 크기·페이지별 위치.

입출력은 1 KiB 버퍼, 행 해석은 최대 4 KiB 단위로 처리한다. 변환 버퍼는 EPUB 페이지 구성 전에 해제한다. 전체 문서의 페이지를 RAM에 보관하지 않고 SD에 순차 기록한다. 페이지 위치 배열은 메모리 여유를 확인하며 128개씩 확장한다. 페이지 개수는 기존 진행률 저장 범위에 맞춰 최대 65,535개이며 메모리 여유에 따라 더 적을 수 있다.

읽을 때는 현재·이전·다음 최대 3페이지만 캐시한다. 여유 메모리가 64 KiB 미만이면 인접 페이지 미리 읽기를 생략한다. 페이지 전환 시 원본을 다시 변환하거나 전체 문서를 다시 조판하지 않는다.

글꼴, 줄 간격, 문단 설정 또는 표시 영역이 바뀌면 캐시를 다시 생성한다. 첫 열기와 캐시 재생성은 기존 TXT보다 오래 걸릴 수 있다. 최근 도서 목록은 구형 버전 4 색인과 새 버전 5 색인을 모두 읽는다.

기존 진행률·북마크는 삭제하지 않는다. 다만 페이지 번호 기반이므로 새 줄바꿈과 문단 간격으로 페이지 수가 달라지면 기존 위치가 달라질 수 있다. 원문 위치 기반 이동은 별도의 후속 개선 대상이다.

## 검증

```powershell
python test/reader/verify_text_document.py
python test/config/verify_txt_page_turn_optimizations.py
python test/config/verify_home_reading_stats.py
$env:PYTHONUTF8='1'
python -m platformio run -e default
```

변환기 검증은 실제 C++ 함수를 정적 단언으로 실행한다. 단일 바이트 입력 분할, 한글·일본어, CRLF, 긴 행, 서식 경계, 코드 펜스 길이, 중첩 링크 괄호, XML 이스케이프, 쓰기 실패 전파 및 구형/신형 진행률 헤더를 검사한다. 소스 연결 검증과 펌웨어 빌드는 실제 기기 렌더링을 대신하지 않는다.

참고: 기존 `test/epub/verify_ruby_render_plumbing.py`는 `page->render`라는 과거 호출 형태만 검사하여 현재의 `page.render`를 실패로 판정한다. TXT·MD 변경 이전 HEAD에도 같은 호출 형태가 있다. 이번 작업에서는 해당 EPUB 코드와 검사식을 수정하지 않았다.

기기에서는 `test/reader/fixtures`의 합성 문서를 SD 카드에 복사해 다음을 확인한다.

1. TXT의 줄바꿈·빈 줄과 MD의 제목·강조·목록·코드가 구분되는지 확인한다.
2. 문단 간격·들여쓰기·양쪽 정렬을 바꿨을 때 캐시가 재생성되고 표시가 반영되는지 확인한다.
3. 작은 여백과 큰 글꼴, 가로 화면에서 목록 오른쪽이 잘리지 않는지 확인한다.
4. 코드 블록이 여러 페이지에 걸쳐도 뒤로/앞으로 이동 시 서식이 유지되는지 확인한다.
5. 다시 열기·북마크 이동·최근 도서 진행률과 기존 EPUB 읽기를 확인한다.
