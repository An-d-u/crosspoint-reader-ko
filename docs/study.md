# Anki 덱 학습

CrossPoint의 **학습** 기능은 CrossPlay Study 형식으로 변환한 Anki 덱을 Xteink X4에서 오프라인으로
복습한다. 카드별 스케줄은 Anki와 같은 FSRS-5 가중치와 학습 단계를 사용하며, 결과는 SD 카드에 즉시
저장된다.

## 덱 넣기

1. Anki에서 덱을 `.apkg`로 내보낸다. 기존 진도까지 옮기려면 내보내기 옵션에서 스케줄 정보를 포함한다.
2. [CrossPlay Study 설치 페이지](https://crossplay.ma-r-s.com/study/)에서 `.apkg`를 변환한다.
3. 생성된 `study` 폴더를 SD 카드 최상위에 복사한다. 최종 구조는 다음과 같다.

   ```text
   /study/<덱 이름>/deck.dat
   /study/<덱 이름>/cards.dat
   /study/<덱 이름>/meta.dat
   /study/<덱 이름>/revlog.dat
   ```

4. 기기에서 **파일 전송**을 열고 표시된 주소에 브라우저로 한 번 접속한다. 브라우저 시각이 기기에
   자동으로 전달되어 오늘 복습할 카드를 정확히 계산한다. 일반적인 절전/깨우기 사이에는 다시 할 필요가
   없으며, 전원을 완전히 껐다 켠 뒤 시계 경고가 보일 때만 반복한다.
5. 홈에서 **학습**을 연다.

## 버튼

- 덱 화면: 가운데 버튼으로 시작하고, 좌우 버튼으로 덱을 바꾼다.
- 문제 화면: 가운데 버튼으로 정답을 본다. 뒤로 버튼은 덱 화면으로 돌아간다.
- 정답 화면: 화면 아래에 표시되는 `다시`, `어려움`, `좋음`, `쉬움` 버튼으로 기억 정도를 평가한다.

각 평가 직후 `cards.dat`와 `revlog.dat`를 플러시하므로, 학습 중 전원이 꺼져도 이미 평가한 카드의
진도는 남는다.

## Anki로 복습 결과 되돌리기

학습 후 같은 CrossPlay Study 설치 페이지에서 SD 카드의 리뷰를 불러오면 Anki에 반영할 수 있다.
`revlog.dat`는 CrossPlay와 동일한 32바이트 레코드 형식이며 카드 ID, 평가, 이전 상태, 경과 일수와 새
간격을 보존한다.

## 현재 범위

첫 버전은 덱 전환, 문제/정답 표시, 네 단계 평가, FSRS 스케줄링, 학습 단계, 영구 저장과 Anki 호환
리뷰 로그를 제공한다. X4 Pro용 CrossPlay에 있는 카드 사진, 통계 그래프, 한 단계 실행 취소, 오디오는
아직 포함하지 않는다.

CrossPlay Study 원본은 MIT 라이선스로 제공되며, 관련 저작권 고지는 프로젝트 `LICENSE`에 포함했다.
